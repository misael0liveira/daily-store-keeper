# UI

Marcar na Conta → Marcar valor total ou Receber uma parte. Após escolher, mesma folha apresenta resumo/formulário.
Vencimento é texto; edição opcional na compra. Entrada cobra valor informado diretamente nos quatro meios.
Usar dois meios na entrada abre editor existente, sem escolha obrigatória intermediária. Cancelar/Voltar preservam parcelas confirmadas.
