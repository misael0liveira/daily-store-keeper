# Command: Nova funcionalidade

Use este fluxo para uma funcionalidade nova.

1. Inspect
2. Plan
3. Implement
4. Review
5. Verify

## Perguntas obrigatórias
- Existe algo parecido já implementado?
- Qual store possui os dados?
- A funcionalidade precisa funcionar offline?
- Existe impacto no Android?
- Existe impacto no Supabase?
- Quais botões/rotas precisam realmente funcionar?

## Critério de aceite
Descrever comportamento observável pelo operador do mini mercado.
