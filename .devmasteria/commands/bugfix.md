# Command: Correção de bug

## Fluxo
1. reproduzir ou localizar a causa;
2. identificar a menor correção;
3. corrigir;
4. procurar ocorrências semelhantes;
5. verificar o fluxo afetado;
6. executar build/testes apropriados.

## Regra
Não corrigir apenas o sintoma visual quando a causa está em rota, estado, store ou integração.
