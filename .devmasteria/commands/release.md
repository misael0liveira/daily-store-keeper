# Command: Release APK

## Objetivo
Preparar uma versão Android sem modificar regras de negócio durante o processo.

## Checklist
- [ ] build web concluído
- [ ] Capacitor sync concluído
- [ ] release Gradle concluído
- [ ] assinatura aplicada
- [ ] APK gerado
- [ ] versionCode/versionName conferidos
- [ ] mecanismo de atualização preservado
- [ ] artefato publicado
- [ ] release latest atualizado quando aplicável

## Regra
Nunca incluir keystore, senha ou segredo no artefato ou commit.
